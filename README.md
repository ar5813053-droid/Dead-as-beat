# Neon Beat

3D neon rhythm-action combat game for Android (Godot 4.3).

**Status:** v0.2.0 — 3D arena, Kenney CC0 soldier character, touch controls, wave combat, beat-synced scoring.

## Play
Push to `main` → GitHub Actions → download **NeonBeat-debug-apk** (or NeonBeat-Android-APK).

## Controls (Android)
- Left stick: move
- ATK / DODGE / JUMP buttons
- Pause

## Desktop
- WASD / arrows move, Space jump, attack/dodge keys from project input map
